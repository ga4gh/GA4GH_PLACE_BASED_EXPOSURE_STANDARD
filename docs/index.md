# GA4GH Place-Based Exposure Metadata Schema

A [LinkML](https://linkml.io) schema describing how an environmental exposure dataset was
linked to cohort participants. One `ExposureLinkageRecord` describes one exposure variable
linked in one cohort.

Status: **Draft** (version 0.1.0), developed by the
[GA4GH Human Exposome Data Standards Study Group](https://www.ga4gh.org/product/human-exposome-data-standards/).
